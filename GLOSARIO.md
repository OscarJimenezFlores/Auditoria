Las siglas de normas se citan como aparecen en la norma original. Los términos en inglés se conservan cuando así se usan en el trabajo profesional.

## Encargo de auditoría

| Término | Significado |
|---|---|
| **Encargo** | El trabajo de auditoría acordado — alcance, criterio, periodo y entregables |
| **Alcance** | Qué se audita y qué queda expresamente fuera |
| **Criterio de auditoría** | La norma, política o requisito contra el cual se compara lo observado |
| **Condición** | Lo que se encontró en la realidad |
| **Hallazgo** | La diferencia entre el criterio y la condición, con su causa y su efecto |
| **Evidencia** | El registro que sustenta un hallazgo. Debe ser suficiente, pertinente y verificable |
| **Papel de trabajo** | Documento que registra el procedimiento aplicado, la evidencia obtenida y la conclusión |
| **Carta de encargo** | Documento que formaliza el trabajo, su alcance y la independencia del equipo |
| **Matriz PBC** | *Prepared By Client*. Lista de información que el auditado debe entregar, con fecha y responsable |
| **Independencia** | Ausencia de vínculos que comprometan el juicio del auditor. Se declara y se salvaguarda |
| **Salvaguarda** | Medida que reduce una amenaza a la independencia |
| **Opinión** | La conclusión general del auditor sobre lo auditado |
| **Auditoría interna / externa** | Interna: dentro de la organización. Externa: por un tercero independiente |

## Pruebas y técnicas

| Término | Significado |
|---|---|
| **CAAT** | *Computer Assisted Audit Technique*. Prueba ejecutada con herramientas sobre datos, no a mano |
| **Prueba de cumplimiento** | Verifica que un control opera como está diseñado |
| **Prueba sustantiva** | Verifica directamente el dato o el saldo, sin apoyarse en el control |
| **Población** | El conjunto completo de transacciones del periodo auditado |
| **Muestreo** | Examinar una parte para concluir sobre el todo. Con CAAT suele evitarse se prueba el 100 % |
| **Ley de Benford** | Distribución esperada del primer dígito en poblaciones naturales de montos. Señala dónde mirar, no prueba fraude |
| **Fraccionamiento** | Dividir una compra para que cada parte quede bajo el umbral que exige aprobación |
| **Autoaprobación** | Que quien registra una operación sea quien la aprueba |
| **Segregación de funciones** | Separar registro, aprobación y custodia entre personas distintas |
| **Cruce de archivos** | Comparar dos fuentes independientes para detectar coincidencias indebidas |
| **Trazabilidad** | Poder seguir un hallazgo hasta la evidencia que lo sustenta |

## Normas y marcos

| Norma | Qué establece |
|---|---|
| **ISO 19011:2018** | Directrices para auditar sistemas de gestión. Define principios, competencia e independencia |
| **ITAF** | *Information Technology Assurance Framework*, de ISACA. Estándares de la profesión |
| **Código de Ética de ISACA** | Principios que rigen la conducta del auditor de sistemas |
| **COBIT 2019** | Marco de gobierno y gestión de TI, base del criterio de auditoría |
| **COSO 2013** | **Marco de control interno.** Cinco componentes y diecisiete principios |
| **NTP-ISO/IEC 27001** | Norma técnica peruana de gestión de seguridad de la información |
| **NTP-ISO/IEC 12207** | Norma técnica peruana de procesos del ciclo de vida del software |
| **ISO 22301:2019** | Norma de gestión de continuidad del negocio |
| **ISO/IEC 27031** | Preparación de las TIC para la continuidad del negocio |
| **CIS Benchmarks** | Configuraciones seguras de referencia para sistemas y servicios |
| **CVSS** | *Common Vulnerability Scoring System*. Escala de severidad de vulnerabilidades |

## Continuidad y seguridad

| Término | Significado |
|---|---|
| **BIA** | *Business Impact Analysis*. Análisis del impacto de la interrupción de cada proceso |
| **RTO** | *Recovery Time Objective*. Tiempo máximo aceptable de interrupción |
| **RPO** | *Recovery Point Objective*. Pérdida máxima aceptable de datos, medida en tiempo |
| **BCP** | *Business Continuity Plan*. Plan de continuidad del negocio |
| **Inmutabilidad** | Propiedad de un respaldo que no puede alterarse ni borrarse durante un periodo |
| **Registro de riesgos** | Inventario de riesgos con su probabilidad, impacto, tratamiento y responsable |
| **SGSI** | Sistema de Gestión de Seguridad de la Información |

| Norma | Qué establece |
|---|---|

| **D. S. 016-2024-JUS** | Reglamento de la Ley 29733, vigente desde marzo de 2025 |

| **D. Leg. 1412** | Ley de Gobierno Digital |
| **Ley 28716** | Ley de Control Interno de las Entidades del Estado |
| **Resolución SBS 504-2021** | Gestión de la seguridad de la información en entidades supervisadas por la SBS |
| **ANPD** | Autoridad Nacional de Protección de Datos Personales |
| **Registro de tratamiento** | Inventario obligatorio de qué datos personales trata la organización, para qué y con qué base legal |
